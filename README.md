基于多光束干涉校正的半导体外延层厚度光谱反演软件 V1.0

1. 项目简介（软著申请定位）

本项目旨在将数模比赛中针对 Si/SiC 半导体外延层厚度测量的核心原创算法，重构为一款具备完整图形界面（GUI）的正规桌面端软件。
核心目的： 满足中国计算机软件著作权「独立可运行、功能完整、独创性」的核心审核要求。
设计思路： 将零散的参赛脚本重构为闭环式、可配置、通用化的完整软件，形成「数据导入 - 预处理 - 核心计算 - 结果分析 - 报告导出」的全流程闭环。

1. 数据导入与管理模块

 支持 csv/txt/xlsx 批量导入、数据预览校验、异常值识别、高反射区(Reststrahlen)自动标记、自定义波段筛选。

从硬编码升级为通用化多格式数据兼容，适配不同设备输出的光谱数据。

2. 光谱数据预处理模块

原有: SG平滑、波谷识别。



新增: 多滤波算法可选、基线校正、极值点自适应识别与筛选、数据归一化、参数可视化调优。

补充工业级预处理全流程，参数用户可配置，适配不同信噪比实测数据。

3. 材料光学常数计算模块

原有: SiC的Sellmeier和Drude-Lorentz模型。



新增: Si/SiC材料库、自定义材料参数配置、光学参数批量计算与波长关系可视化。

封装核心光学模型为可自定义材料库，大幅扩展软件物理适用范围。

4. 双光束干涉计算模块

原有: 线性回归初估、非线性拟合。



新增: 拟合边界自定义、迭代收敛控制、多角度联合拟合、指标(R²/RMSE)实时输出。

完整落地论文核心算法，优化鲁棒性，适配不同入射角实测数据。

5. 多光束干涉校正模块

原有: 4项指标判定、Airy模型、差分进化反演。



新增: 多光束效应自动判定与模式推荐、校正前后结果对比、灵敏度分析。

100%复用论文创新算法，软著申请的核心独创性支撑。

6. 结果分析可视化模块

原有: 基础绘图。



新增: 拟合与实测对比、残差分析、参数相关性热图、置信区间分析、高清图片导出。

升级为标准科研级可视化体系，完善软件的商用完整性。

7. 报告与结果导出模块

原有: 控制台打印。



新增: 计算结果批量导出(excel)、标准化分析报告自动生成(word/pdf)，含图表。

从脚本升级为完整商用软件的闭环能力，软著极速通过的利器。
